# Mental Health in Tech — Exploratory Data Analysis

## Project Overview
This project explores mental health in the technology workplace using Python-based Exploratory Data Analysis (EDA). It examines survey responses to identify patterns related to mental health, workplace support, and help-seeking behaviour.

## Objectives
- Explore mental health survey responses and workplace trends.
- Understand relationships between treatment, benefits, and support.
- Visualize findings using charts and a country-level respondent map.
- Identify potential opportunities for improving employee well-being.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- Plotly (for geographic visualization, if used in the notebook)

## Project Contents
- `Mental_Health_in_Tech.ipynb` — data analysis, visualizations, and interpretations.

## Key Learning Outcomes
- Data cleaning and preparation
- Exploratory data analysis
- Data visualization and interpretation
- Translating analytical findings into potential business recommendations

## Important Note
The findings describe the survey respondents represented in the dataset. Respondent counts by country should not be interpreted as the prevalence of mental health conditions in those countries.

## How to Use
Open the notebook on GitHub, or download it and run it using Jupyter Notebook after installing the required Python libraries.
